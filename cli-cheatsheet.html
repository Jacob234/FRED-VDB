FRED-VDB CLI Cheatsheet

Semantic search over 840K+ Federal Reserve Economic Data series

fred-ingest Build the index ingest

# Basic ingest (reads $FRED_API_KEY)
fred-ingest

# Explicit key + custom dir
fred-ingest --api-key YOUR_KEY --data-dir ./mydata

# Only popular series, skip category walk
fred-ingest --min-popularity 20 --skip-categories

# Richer embeddings (slow, ~1 API call/series)
fred-ingest --enrich-tags

# Preview only, no writes
fred-ingest --dry-run

# Wipe state and rebuild
fred-ingest --force

# Verbose logging
fred-ingest --log-level DEBUG
Resumable: re-running continues from the last checkpoint. Use --force to start fresh.

fred-search Query the index search

# Basic search
fred-search "consumer price index"

# More results
fred-search "unemployment rate" --top-k 20

# Filter by frequency
fred-search "GDP growth" --frequency Quarterly

# Only popular + JSON output
fred-search "fed funds rate" --min-popularity 50 --json

# Include stale series
fred-search "M2 money supply" --include-stale

# Pure vector similarity
fred-search "inflation" --no-popularity-boost

# Combine everything
fred-search "labor market" --frequency Monthly \
  --min-popularity 30 --top-k 5 --json

fred-fetch Get observation data fetch

# Fetch last 12 observations
fred-fetch UNRATE --last 12

# Multiple series, date range
fred-fetch UNRATE DGS10 --start 2020-01-01

# JSON output for programmatic use
fred-fetch CPIAUCSL --last 24 --json

# Specific date window
fred-fetch PAYEMS --start 2023-01-01 --end 2024-12-31
FlagDefaultDescription
SERIES_IDrequiredOne or more FRED series identifiers

--end YYYY-MM-DDtodayObservation end date

Quick Setup

# Install the package
uv pip install -e .

# Set your API key
export FRED_API_KEY=your_key_here

# Build the index (resumable)
fred-ingest

# Search
fred-search "consumer price index"

# Fetch data for a series you found
fred-fetch CPIAUCSL --last 12 --json
